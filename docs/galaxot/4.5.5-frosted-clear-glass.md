# 4.5.5 — Frosted and Clear Glass: full implementation review

**Branch:** `opentune-rebuild-v1` · **Dependency:** 4.5.4 canonical GlassEngine · **Reworked together with:** 4.5.6.

## Material identities

Frosted and Clear are **two independent optical/material policies** sharing exactly one renderer. They are not simply color presets.

| | Frosted | Clear |
|---|---|---|
| Optical blur request (dp) | 14 | 2 |
| Lens | off (surface diffusion) | on (refraction) |
| Refraction | .030 | .115 |
| Curve | .080 | .21 |
| Dispersion | 0 | .0045 |
| Dark live tint alpha | .22 | .035 |
| Light live tint alpha | .48 | .085 |
| Vibrancy | off (readable diffusion) | on |
| Specular finish | broad white-to-accent gradient | crisp, restrained sheen |
| Directional rim | soft / wide | bright / defined |
| High-quality fallback | theme surface ≥ .93 alpha | theme surface ≥ .93 alpha + SDK-safe static lens |

A Material 3 primary accent is injected by the caller; there is **no baked-in brand cyan/blue**. Current dynamic theme, dark theme, and pure black remain supported.

## Architecture

- `GalaxGlassMaterials.kt` contains semantic surface, fallback, highlight, lens/vibrancy and rim policies.
- `GalaxGlassContracts.kt` keeps the pure render planner and prevents legacy `GlassPreset.SOFT` overrides on non-Classic selections.
- `GalaxGlassSurface.kt` combines active theme, selected mode, power/low-memory capability and reduced-motion policy.
- `GlassEngine.kt` uses the existing Kyant backdrop and Sky static renderer; optional Compose brush layers add sheen and an edge rim without a second blur shader.
- Frontends: `GalaxGlassSurface` for clipped containers; `Modifier.galaxGlassEffect` for hosts with pre-existing backgrounds.

## Runtime limitations

Backdrop blur and lens depend on a **real Kyant Backdrop**. Android 13+ static Sky shader does not imply real background blur. Without live capture, Frosted uses a high-contrast tinted surface (not a fake blur); Clear can use the existing Sky optical lens if policy allows it. Power-save, low RAM and scrolling surfaces use the cheap tint/outline branch; the LOW tier also strips sheen gradients and directional rim brushes. Reduced motion caps optics. A selected mode supplied through `LocalGalaxGlassMode` now wins over the legacy on/off boolean, but the global persistent selector is reserved for **4.5.7**.
