# 4.5.6 — Blur Glass, Classic Liquid Glass and Disabled

Branch: `opentune-rebuild-v1`. These material variants reuse the one Glass Engine established in 4.5.4. Frosted and Clear from 4.5.5 remain unchanged.

## Rendering contract

- **BLUR**: 12px optical blur baseline (converted to dp by renderer), low refraction (0.025), minimal edge (0.10), no chromatic dispersion. Surface diffusion uses white 16% on dark / 30% on light, soft outline 17% / 35%. Live Kyant Backdrop uses blur and vibrancy without the Kyant lens; existing Sky static and tint-and-outline fallbacks remain in force.
- **CLASSIC**: `GlassPreset.STANDARD.optics` and original semantic `surfaceGlass` / `outlineGlass` tokens. The renderer's existing lens/highlight, shadow, blur, effects, and callers remain unchanged.
- **DISABLED**: `resolveGalaxGlassPlan` selects `GlassRenderMode.OPAQUE`, `GlassFallbackStrategy.OPAQUE` and LOW tier. `GalaxGlassSurface` draws an opaque theme surface, clipped to the requested shape and with the existing opaque border. `Modifier.galaxGlassEffect` intentionally remains a no-op when disabled (same modifier contract as 4.5.4); its host is responsible for its own background.

## Compatibility and limitations

The existing Liquid Glass on/off preference remains the source of truth until the 4.5.7 selector ships. No persistence migration, MusicService changes, new shaders or second backdrop. The default mode is Classic. Low-RAM, battery saver, reduced-motion and SDK fallback rules remain as defined in 4.5.4.

The new `enableLens` optional argument defaults to true, leaving every legacy `openTuneGlassEffect` and `GlassSurface` caller unchanged. Only Galax BLUR disables the live lens. Static Sky shaders are still allowed by the central policy, so a device fallback can have a slightly different optical character.

## Validation

Run `testUniversalDebugUnitTest lintUniversalDebug assembleUniversalDebug` and build `assembleArm64Debug` locally. Verify Classic before/after behavior, Blur in both dark and light modes, Disabled opacity and legibility, accessibility/reduced motion, battery saver, unknown-duration tracks, navigation/MiniPlayer, full player, queue, offline and notifications. Full five-way mode selection is reserved for 4.5.7; to evaluate individual materials before that, inject `LocalGalaxGlassMode` in a debug-only composition.

Changes committed to the branch are not proof of CI or on-device success.
