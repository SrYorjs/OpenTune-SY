# 4.5.4 — Galax Glass Engine central

**Branch:** `opentune-rebuild-v1` · **Project:** GalaxOT · **Scope:** architecture, capabilities, fallbacks, performance and initial integration.

## Objective

Evolve the canonical Glass Engine built in phases 3.x and 4.x, without adding a competing renderer or changing MusicService. Kyant Backdrop and the existing Sky/Cloudy static optical fallback remain the rendering backend. This stage creates the common contracts for the five planned materials, while final distinct visual treatments will be implemented in 4.5.5 and 4.5.6; the persisted five-mode switch belongs to 4.5.7.

## Source files and changes

- `core/designsystem/glass/GalaxGlassContracts.kt`: `GlassMode` (FROSTED, CLEAR, BLUR, CLASSIC, DISABLED), `GlassSurfaceType`, `GlassSurfaceSpec`, `GlassCapabilities`, `GlassPerformanceTier`, `GlassFallbackStrategy`, `GlassRenderPlan` and deterministic policy functions.
- `core/designsystem/glass/GalaxGlassSurface.kt`: two Compose frontends for any surface or composable modifier. Draws through the single `openTuneGlassEffect` / `GlassSurface` backend, rather than stacking blur engines.
- `core/designsystem/glass/GlassEngine.kt`: optional `renderModeOverride`, `optics` and `allowStaticShader`, preserving defaults and earlier signatures. No breaking change to existing Player V1–V8 callers.
- `FloatingNavigationToolbar.kt`: uses `GlassSurfaceType.NAVIGATION`, preserving the previous SOFT optics from the navigation bar.
- `PlayerGlassEffect.kt`: MiniPlayer uses `GlassSurfaceType.MINI_PLAYER` and its original `GlassPreset.SOFT`.
- **No Media3 change:** play, seek, crossfade, offline, Together, Radio, notification art, Queue and existing preference keys are unchanged.

## Render policy

| Condition | Tier | Path |
|---|---|---|
| Live Kyant Backdrop available, no budget constraints | High | Backdrop live + bounded optics |
| Reduced motion or forced balanced | Balanced | Backdrop with blur capped and chromatic dispersion off |
| Android 13+ without live backdrop, standard budget | Balanced/High | Sky/Cloudy static lens fallback |
| Older Android without live backdrop | Balanced | Static tint + outline; never claim real blur |
| Scrolling item, battery saving or low RAM | Low | Tint + outline **without extra shader** |
| Existing glass toggle OFF or mode DISABLED | Low | Opaque clipped surface, no glass renderer |

SDK/API cannot identify GPU performance reliably. We use explicit, conservative Android capabilities instead of guessing frame rates from the SDK version. `GlassCapabilities.hasRenderEffect` is only an availability signal; a live Backdrop is claimed only when the real `LocalLiquidBackdrop` is supplied.

The five modes now have bounded optical defaults, but the final Frosted/Clear/Blur appearance and their individual visual tuning are reserved for 4.5.5–4.5.6. The local mode defaults to null, so the existing Liquid Glass preference remains the source of truth until 4.5.7.

## Branding correction in the same batch

The **user-supplied PNG with real alpha** was decoded and resized to Android densities (mdpi–xxxhdpi). Adaptive foreground is centered within a safe 320px canvas. The icon background resource and legacy background assets are transparent. The GalaxOT launch splash keeps the dark galactic backdrop intentionally. Android launchers may still impose their own masks and themed-icon treatment.

The **applicationId** stays `com.Arturo254.opentune`, with the original signing/deep-links, app data and offline storage intact.
