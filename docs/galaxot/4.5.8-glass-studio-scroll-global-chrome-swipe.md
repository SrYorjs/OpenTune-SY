# GalaxOT 4.5 — Glass Studio scroll, shared material and spring tab gestures

**Scope:** `opentune-rebuild-v1`; no logo, splash, application ID, player engine or provider change.

## 1. Scroll everywhere in Glass Studio

`ui/screens/settings/GalaxLiquidSettingsScreen.kt` now has **one** root `Column.verticalScroll(rememberScrollState())` enclosing wallpaper chooser, whole preview, 14 material cards, and tuning sliders. The old fixed 430dp preview + `Column.weight(1f).verticalScroll` area was removed. Normal vertical swipes can start anywhere except active slider gestures. The draggable lens uses `detectDragGesturesAfterLongPress`, allowing ordinary vertical scrolling without hijacking it.

## 2. Swipeable navigation: Home / Search / Genres / Library

`ui/component/FloatingNavigationToolbar.kt`: horizontal drags inside the navigation capsule select the previous/next entry in the existing `items` ordering; taps still work. A spring-animated capsule measures and follows the active tab in pixels, even as its label expands. A limited stretch gives tactile feedback while swiping; selection haptics are routed through existing `GalaxHapticCue`. Gestures do NOT apply to NavHost body, search text fields, playlists, slider tracks or the OS back edge.

`core/designsystem/motion/GalaxMotionEngine.kt`: top-level page enter/exit slides now use matched, softened springs and fades. Reduced-motion policy still skips all decorative transitions.

## 3. Material everywhere it is safe

`ui/component/LiquidGlassBackdrop.kt` now forwards the legacy `Modifier.liquidGlassSurface` signature to **GalaxLiquidRenderer**, so shared pill buttons, icon buttons and control clusters no longer use the obsolete GlassEngine optics.

`core/designsystem/liquid/GalaxLiquidChrome.kt`: inexpensive, variant-sensitive reflectivity, spectral edge and translucent surface treatment for source-internal controls. **No new Kyant background capture is performed inside NavHost**, preserving the separation required after the Samsung Android 17 native RenderThread SIGSEGV. The material follows `LocalGalaxLiquidVariant`, `LocalGalaxLiquidTuning` and the chosen variant's `galvanicFinish`.

Consumers include `LiquidGlassCard` (which underlies general settings groups/cards), `Material3SettingsGroup`, `NewActionButton`, `NewIconButton`, `MenuSurfaceSection` and `OpenTuneButton`. Buttons have small spring press motion. Top app bar actions and account icon use shared Glass controls; the top fade is lighter when enabled. The existing Kyant refraction is reserved for sibling overlays (navigation and MiniPlayer) with their actual captured backdrop.

**Important distinction:** the lightweight chrome on controls *inside* source screens is translucent specular styling, **not** independently live-blurred route sampling. Adding arbitrary `drawBackdrop` calls inside the captured NavHost would risk repeating the native recursive RenderNode failure. This is a deliberate safety/performance tradeoff. Inactive/OFF mode retains the normal Material 3 opaque rendering.

## 4. S24 FE QA

1. Settings → Appearance → Galax Liquid Glass: swipe vertically starting over photo preview, material cards, between controls, to the very last slider; header scrolls out and back; no tiny scrolling rectangle.
2. Hold the lens ~half a second, then drag: it moves. Short/regular swipes should scroll normally.
3. In main navigation capsule drag from Home → Search → Genres → Library and reverse; verify moving capsule, direction, haptics and navigation. Also tap each tab.
4. Check user-selected material and corner radius on mini player, bottom tabs, account button, main toolbar and buttons/cards/settings groups; OFF restores baseline.
5. Press menus/action tiles, verify spring squash and release; verify reduced-motion turns off unnecessary spring/scale.
6. Search, play/pause, offline, seek, queue, Together, notifications, scroll on long song lists, background/foreground and battery saver.
7. Watch Logcat for `RenderThread`, `SIGSEGV`, `OpenGLRenderer`, `libhwui.so`; do not interpret unit tests alone as GPU safety.
8. Verify Kotlin compilation, unit tests, Lint, universal/arm64 APK. No unverified claim of device stability.
