# Fase 4.5.1 — GalaxOT: rebranding oficial

**Rama:** `opentune-rebuild-v1`  
**Marca visible:** GalaxOT  
**Fuente gráfica:** última imagen original entregada por el usuario (`269960.png`, RGBA, 2048 × 2048), sin sustituir el diseño por un icono genérico.

## Alcance realizado

### Nombre y compatibilidad de instalación

- `res/values/app_name.xml` → `GalaxOT` (nombre de launcher, sistema y pantallas que consultan `R.string.app_name`).
- Se actualizaron las apariciones textuales de la marca anterior en los valores de cadenas visibles de `values` y `values-es` (`strings.xml` y `opentune_strings.xml`). **Los nombres de los recursos** (por ejemplo, `OpenTune_canvas`) permanecen para no romper referencias del código.
- El README ahora presenta GalaxOT, pero conserva la atribución, licencias y enlaces originales de OpenTune.

**Invariantes preservadas:**

| Configuración | Valor / decisión |
| --- | --- |
| `applicationId` | `com.Arturo254.opentune` — sin cambios |
| `namespace` | `com.arturo254.opentune` — sin cambios |
| Deep link de Together | `opentune://together` — sin cambios |
| Proveedor de archivos | `${applicationId}.FileProvider` — sin cambios |
| Claves DataStore / migraciones Room | sin cambios |
| Nombre de tema base `Theme.OpenTune` | conservado como parent de compatibilidad |

Para que Android actualice una instalación sin borrarla, **también debe coincidir la firma del APK**. Cambiar de debug a release con otra firma no conserva la misma actualización automática aunque el `applicationId` sea idéntico. Se conserva el sufijo de depuración `.debug` donde ya existía.

### Imagen original, iconos y splash

- El logo oficial se guarda en `res/drawable-nodpi/galaxot_logo.webp`, derivado directamente del PNG entregado (sin rediseñar sus anillos ni centro).
- El foreground adaptativo respeta el área segura central: `res/drawable-nodpi/galaxot_launcher_foreground.webp`.
- Icono monocromático derivado del mismo arte: `res/drawable-nodpi/galaxot_launcher_monochrome.webp`.
- `mipmap-anydpi-v26/ic_launcher.xml` enlaza el fondo `#071021`, el foreground de GalaxOT y la versión monochrome para temas Android.
- Se reemplazaron **los 20 iconos PNG legacy** en `mipmap-mdpi`, `hdpi`, `xhdpi`, `xxhdpi` y `xxxhdpi` (launcher, foreground, background, monochrome).
- Se añadió `android:roundIcon` al manifiesto usando el mismo adaptive icon.
- `Theme.GalaxOT` mantiene `Theme.OpenTune` como parent, y utiliza `galaxot_launch_background.xml` para Android 8–11.
- Android 12+ utiliza atributos nativos `windowSplashScreenBackground`, `windowSplashScreenAnimatedIcon` y `windowSplashScreenIconBackgroundColor` con los recursos de marca.
- `galaxot_brand.xml` define colores iniciales: space black, deep space, nebula, galaxy blue, halo e ice. La aplicación integral de estos tokens a todas las pantallas corresponde a **4.5.2**.

### Regresión automática

`GalaxOTBrandingContractTest` debe asegurar que no cambió el `applicationId`, las rutas profundas y el namespace; que las etiquetas y los temas apuntan a la nueva identidad; que las imágenes PNG y WEBP son binarias reales y están presentes para todas las densidades; que el splash está configurado para API 26–30 y API 31+.

### Prueba en el dispositivo

1. Antes de instalar la nueva compilación, anotar preferencias y archivos descargados.
2. Instalar **con la misma firma** que ya usa la instalación (no desinstalar y no borrar datos).
3. Verificar el nombre **GalaxOT** y el icono con forma original en launcher, ajustes del sistema y recientes.
4. Probar icono monocromático en el launcher con iconos temáticos.
5. Forzar cierre y abrir: comprobar splash fondo azul espacial e icono sin flashes blancos.
6. Probar modo oscuro, playlists, preferencias, biblioteca offline y las URLs existentes de Together.
7. Comparar con APK previa y probar después Build universal, Lint y tests.

**Límite:** esta etapa es branding y splash; el rediseño visual de Home, Buscar, Biblioteca, Player y el Glass Engine llega en 4.5.2–4.5.15. No se atribuyen mejoras de rendimiento a esta fase.
