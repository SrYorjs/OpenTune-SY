# GalaxOT 4.5.4–4.5.7 — Kyant AndroidLiquidGlass rebuild

**Upstream:** https://github.com/Kyant0/AndroidLiquidGlass
**Reference branch / version:** `kmp` / `io.github.kyant0:backdrop:2.0.1`
**Code branch:** `galax-kyant-glass-rebuild`, forked from `opentune-rebuild-v1`
**Scope:** Glass only. DO NOT change app branding, launcher, transparent icon, splash, applicationId, theme font, player layouts, Media3, source providers, downloads, or queue.

## Why the prior implementation failed

The 4.5.7 update wrapped animated `NavHost` content with Kyant `rememberLayerBackdrop` / `Modifier.layerBackdrop`, then reused the backdrop inside foreground glass surfaces. Samsung SM-S721U Android 17 Logcat showed `SIGSEGV` on `RenderThread` with deeply repeating `libhwui.so RenderNode::prepareTreeImpl / SkiaDisplayList::prepareListAndChildren` frames. This suggests a cyclic/recursive recorded layer tree. The original version was rolled back to opaque/tinted fallbacks; that prevented the suspected capture but also removed native refraction.

## How Kyant actually works

The upstream `app/src/androidMain/.../BackdropDemoScaffold.kt` captures a **standalone wallpaper Image** using a `LayerBackdrop`, and overlay controls use `Modifier.drawBackdrop`, `effects { vibrancy(); blur(); lens() }`, `highlight`, `shadow` and `onDrawSurface`. Upstream separately exposes `rememberCanvasBackdrop(onDraw)` which provides a pure `DrawScope` source with `isCoordinatesDependent = false`. It **does not allocate/record a GraphicsLayer** or depend on `NavHost` layout coordinates.

## Rebuild: safe native optics, no self-capture

```text
MainActivityScaffold (one global mode + theme)
   ├── LocalSky (historic Classic)
   ├── LocalGalaxGlassMode (DataStore, 5 choices)
   └── rememberGalaxCanvasBackdrop(pureBlack) (new modes only)
        ├── Kyant rememberCanvasBackdrop, no RenderNode recording
        ├── Material3 ambient gradient (galactic colors)
        ├── LocalLiquidBackdrop + LocalGalaxSafeCanvasBackdrop
        └── GalaxGlassSurface / Modifier.galaxGlassEffect
             ├── capability planner + power/memory/motion budget
             └── GlassEngine.openTuneGlassEffect
                   ├── Kyant drawBackdrop / blur / lens / vibrancy
                   ├── tint/border fallback when unsupported
                   └── opaque surface when disabled
```

### Five modes

- **FROSTED** — higher blur/diffusion (14 dp), muted rim/reflection, no refraction lens/vibrancy.
- **CLEAR** — low blur (2 dp), strong Kyant refraction lens and chromatic aberration, crisp rim and translucency.
- **BLUR** — deep Kyant blur (18 dp), no refraction or vibrancy, subtle edge.
- **CLASSIC** — original `GlassPreset`, original Skydoves/Sky path; no new CanvasBackdrop source to avoid baseline drift.
- **DISABLED** — no Kyant draw calls or Glass effect; opaque readable components.

Render effects are native Kyant 2.0.1. No additional backdrop implementation, reflection shader, image capture, screen recording or `RenderEffect` clone is added. The five-way picker in Appearance remains persistent and backward-compatible with `LiquidGlassNavBarKey`.

### Important limitation

The safe CanvasBackdrop draws a **synthetic Material 3 ambient galaxy gradient**, not a screenshot of the navigation content or dynamic artwork. Kyant really performs blur/refraction on that source, but this revision must NOT be marketed as authentic *behind-navigation page-content blur*. A physically accurate frosted view of scrolling content requires a future scoped source capture **only after** the Samsung Android 17 render-node recursion is isolated and eliminated with an independent test. Never use `Modifier.layerBackdrop` directly on `NavHost` again.

### Crash prevention and capability matrix

- API 33+ (Android 13+): only new materials may receive the canvas source.
- Android 17 / API 37+: planner permits native new-material optics only when `hasSafeCanvasBackdrop == true`; accidentally supplied arbitrary `Backdrop` still forces `TINT_AND_OUTLINE` fallback.
- Battery saver, low-RAM or scrolling surfaces: no expensive native effects, use low-tier tint + border without specular gradients.
- Reduced motion or explicitly lower quality: balanced optical parameters.
- Older Android: noncapturing fallback. Classic unchanged. Disabled always opaque.
- The source is remembered with theme colors and recomposes when the dynamic theme changes, and is not copied across whole routes.
