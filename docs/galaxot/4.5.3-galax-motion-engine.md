# 4.5.3 — Galax Motion Engine

Rama `opentune-rebuild-v1`. Objetivo: una **única gramática de movimiento** para GalaxOT, con integración real en la navegación, los botones base, el vidrio actual y la preferencia de accesibilidad. No modifica MusicService, Media3, descargas, QueueController ni SourceResolver.

## Arquitectura

```text
Preferencias de Apariencia                  Android Animator Duration Scale
     │ Reduce motion ON/OFF                            │
     └───────────────┬──────────────────────────────────┘
                     ▼
        OpenTuneTheme / LocalMotionDurationScale
                     │
         ProvideOpenTuneDesignSystem
                     │
             GalaxMotionPolicy
       ┌─────────────┼──────────────┐
       ▼             ▼              ▼
  NavHost V1–V8   Galax Press    Galax Haptic
  enter/exit/pop  + LiquidGlass  feedback
     │                 │              │
     └────────────── Componentes UI ──┘
                                   │
                       LocalHapticFeedback
                       respeta EnableHapticFeedbackKey
```

## API y funcionamiento

**`core/designsystem/motion/GalaxMotionEngine.kt`**

- `GalaxMotionPolicy`: animación de navegación, press spring, timing, recorrido reducido y umbrales de swipe.
- `galaxEnterTransition` / `galaxExitTransition`: helpers para transiciones de entrada/salida y navegación inversa (incluyendo tabs, Search y otras rutas). Recuperan los parámetros ya probados: spring 0.90/560 para tabs, 0.85/400 para páginas, desplazamientos 1/7–1/9 y fades históricos.
- `GalaxSwipeAction` / `galaxSwipeAction`: decisión geométrica pura y testeable; respeta distancia, velocidad y modo RTL. **No ejecuta** next/previous/seek ni consume eventos. La adopción de gestos por pantallas queda para 4.5.8–4.5.13, conservando las acciones históricas de V5.
- Con `reducedMotion` activado, rutas `EnterTransition.None` / `ExitTransition.None` y specs `snap()`. **No desactiva los gestos funcionales**.

**`core/designsystem/motion/GalaxInteractions.kt`**

- `galaxPressFeedback`: microescala 0.97 basada en interacción `MutableInteractionSource` y `animateFloatAsState`. Con movimiento reducido no crea un layer ni decoraciones.
- `rememberGalaxHapticFeedback`: señales `SELECTION`, `CONFIRM` y `LONG_PRESS` a través del `LocalHapticFeedback` ya filtrado por `EnableHapticFeedbackKey`. No se accede a Vibrator directamente.
- Consumidores reales: `OpenTuneButton`, `OpenTuneIconButton` y la barra de navegación flotante.

**Integraciones de producción**

- `MainActivityScaffold`: las cuatro transiciones (enter, exit, popEnter, popExit) comparten los helpers. La altura flotante usa `galaxMotion.navigationBarSpec` en vez de declarar un spring propio. La ruta de navegación permanece inalterada.
- `LiquidGlassControls`: su deformación elástica desaparece en modo reducido; las operaciones de clic y desplazamiento siguen disponibles.
- `OpenTuneTheme`: usa `LocalMotionDurationScale` y un override local con escala 0 cuando el usuario selecciona reducir movimiento o el sistema la desactiva. Esto cubre las animaciones decorativas de Material 3, las transiciones de color, los componentes heredados y Compose. **No altera los tiempos de Media3**.
- `MainActivityThemeHost`: observa `GalaxReduceMotionKey` de DataStore. Cambio reactivo sin requerir reiniciar.
- `AppearanceSettings`: interruptor «Reducir movimiento» (inglés y español) junto al feedback háptico; default OFF para respetar animaciones actuales. Se conservan todas las otras claves.

## Alcance y límites

Los springs propios de los Players V1–V8 y sus gestos/animaciones *no se sustituyen* por nuevos efectos que puedan romper el seek o las colas; al tener un durationScale=0 sus animaciones Compose se vuelven instantáneas, pero la reproducción y las acciones son independientes. En 4.5.8–4.5.13, las pantallas reconstruidas deberán usar estas primitivas y sus propios shared-element transitions cuando se conecten rutas individuales. No se proclama una mejora de FPS o batería sin Perfetto/Profiler.

## Prueba en S24 FE

1. Abrir y cerrar Home/Search/Library y una canción, ir hacia atrás y comprobar transiciones y dirección.
2. Activar «Reducir movimiento», repetir; deben desaparecer deslizamientos, zoom y elasticidad sin dejar de navegar.
3. Desactivar y comprobar que regresan suavemente.
4. Ajustar «Escala de duración de animador» a OFF en opciones del desarrollador, validar que se respeta incluso con preferencia OFF; restaurar el ajuste del sistema.
5. Activar/desactivar feedback háptico, pulsar botones y tabs flotantes; no debe vibrar cuando está apagado.
6. Probar V1–V8, reproducción, gestures V5, Queue, Lyrics, MiniPlayer, fullscreen, crossfade, Canvas y fuentes offline.
7. Verificar accesibilidad (TalkBack, fuentes grandes, velocidad de transición y contraste), sin depender de efectos visuales para interpretar controles.
