# 4.5.7 — Android 17 RenderThread native crash: incident and hotfix

**Incident:** 2026-10-17 · **Device from user Logcat:** Samsung SM-S721U (S24 FE), Android 17 / API 37 · **Application:** `com.Arturo254.opentune.debug`

## Observed evidence

User activates one of the new Galax Glass choices, and Android terminates the process. The supplied Logcat records:

```text
Fatal signal 11 (SIGSEGV), code 2 (SEGV_ACCERR)
thread: RenderThread, pid: 5102
libhwui.so: RenderNode::prepareTreeImpl
libhwui.so: SkiaDisplayList::prepareListAndChildren
Cause: stack pointer is not in a rw map; likely due to stack overflow
```

The native tombstone repeatedly alternates the two RenderNode tree traversal functions, consistent with a recursive/cyclic RenderNode graph. This is **not** a caught Java/Kotlin exception; try/catch cannot recover a RenderThread SIGSEGV.

## Correlation and likely cause

4.5.7 attached Kyant's `rememberLayerBackdrop { ... }` and `Modifier.layerBackdrop(backdrop)` directly to dynamically animated `NavHost` route content while passing the same captured `Backdrop` through `LocalLiquidBackdrop` to overlay `drawBackdrop` consumers. Only new Frosted/Clear/Blur selections entered that rendering path, matching the user-reported trigger. This is a strong root-cause hypothesis; the log alone cannot prove exactly which RenderNode edge forms the cycle.

## Containment implemented

- `MainActivityScaffold.kt`: **remove** `rememberLayerBackdrop` / `Modifier.layerBackdrop` on `NavHost`; explicitly provide `LocalLiquidBackdrop provides null` in the shell. No native graph capture, including after relaunch with an already persisted failing Glass mode.
- `GalaxGlassContracts.kt`: for new modes on Android API 37+, do not request Skydoves static lens either; use `TINT_AND_OUTLINE`. Retain Classic's proven historical Sky/Cloudy path; do not change on/off migrations.
- `GalaxGlassMaterials.kt`: differentiate the shader-free material surfaces (Frosted higher-opacity diffusion; Clear visibly more transparent with bright rim; Blur denser and quieter); preserve fallback contrast and quality tiers.
- Unit regressions: `GalaxGlassSelectionTest` prevents reintroduction of captured NavHost; `GalaxGlassContractsTest` asserts Android 17 render plan; `GalaxGlassMaterialsTest` verifies three different safe opacities. 

**Tradeoff:** Frosted, Clear and Blur currently use a non-capturing visual fallback rather than authentic live background blur/refraction. The setting remains functional without deleting data, but native optics must not be claimed until separately implemented and validated.

## Proposed future restoration (not included in hotfix)

Build a **non-recursive, isolated capture architecture**, ideally bounded to explicit behind-glass surfaces rather than NavHost's animated tree. Investigate Kyant 2.0.1 usage and Android 17 hwui behavior; use debug-only opt-in, fixed graph ownership, no self/descendant sampling, and feature rollback. Device-test short and long navigation animations, rotating, crossfades, background/foreground, notification shade, 60/120Hz, low RAM, battery saver, memory and RenderThread diagnostics. Require green unit tests, Lint, universal/arm64 APK, plus real device confirmation before enabling live backend again.

Do not uninstall or clear app data. Update debug APK **in place** to recover from persisted Glass selection.
