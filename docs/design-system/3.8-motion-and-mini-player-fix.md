# 3.8 — Sistema de motion y animaciones

Rama: `opentune-rebuild-v1`
Fecha: 2026-10-10

## Objetivo

Centralizar springs y tiempos de transición sin provocar cambios de
comportamiento, reescrituras del Player o afectaciones en playback.

## Contrato

`OpenTuneDesignSystem.motion` expone los presets:

| Preset | Valores anteriores |
| --- | --- |
| navigationBar | spring damping 0.86, stiffness 520 |
| bottomSheet | spring damping 0.88, stiffness 430 |
| bottomSheetSoft | no bouncy + low stiffness |
| miniPlayerSwipeSettle | no bouncy + medium stiffness |
| miniPlayerInfoSlide | spring damping 0.86, stiffness 520 |
| miniPlayerArtworkSlide | spring damping 0.86, stiffness 560 |
| glassPress | spring damping 0.78, stiffness 620 |

Los tiempos de transición del mini-player permanecen iguales:
info fade-in 110 ms, slide-out 140 ms, fade-out 100 ms,
artwork fade-in 90 ms, slide-out 120 ms, fade-out 90 ms.

Compose mantiene el respeto al ajuste de duración de animaciones del
sistema operativo; no se fuerza una duración rígida propia de la app.

## Migración y compatibilidad

`NavigationBarAnimationSpec`, `BottomSheetAnimationSpec` y
`BottomSheetSoftAnimationSpec` delegan a los presets centrales;
sus nombres siguen intactos para los antiguos consumidores.

`MiniPlayerComponents.kt` utiliza motion tokens en gesto de swipe y
en las transiciones de texto y artwork, sin cambiar el umbral de swipe.
`LiquidGlassControls.kt` utiliza el token de elastic press.

No se migran en masa todas las transiciones de navegación y otras
features; ese trabajo pertenece a 3.15. No se modificó el engine de
reproducción, el crossfade musical, ni el diseño óptico del glass (3.9).

## Fix: mini-player sin Liquid Glass

Causa identificada: `liquidGlassSurface()` no aplica clip si Liquid
Glass está desactivado. El fondo del mini-player estaba antes de esa
llamada y permanecía rectangular.

Corrección:

- `OpenTuneDesignSystem.shapes.miniPlayer` = 32 dp;
- `Modifier.clip(miniPlayerShape)` siempre antes de `.background()`;
- `liquidGlassSurface(shape = miniPlayerShape)` mantiene la rama glass;
- el modo opaco obtiene borde de 1 dp derivado de `MaterialTheme.outline`
  y el modo glass evita contorno duplicado;
- las opacidades anteriores 0.82 pure black / 0.88 normal se conservaron
  en tokens de superficies;
- el clip también contiene el contenido desplazado por swipe.
