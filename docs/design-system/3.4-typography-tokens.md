# 3.4 — Tokens de tipografía

Fecha: 2026-10-10
Rama: `opentune-rebuild-v1`

## Objetivo

Crear nombres semánticos para texto propio de OpenTune sin sustituir
`MaterialTheme.typography`, modificar `ui/theme/Type.kt`, incorporar nuevas
fuentes ni fijar tamaños adicionales.

## Fuente de verdad

`OpenTuneTheme` ya decide `MaterialTheme.typography` según
`AppFontStyle.OPEN_TUNE`, `AppFontStyle.SYSTEM` y
`AppFontStyle.MONOCRAFT`. El Design System deriva sus tokens de ese objeto:

```text
AppFontStyle preference
         ↓
Type.kt / withAppFont
         ↓
MaterialExpressiveTheme.typography
         ↓
ProvideOpenTuneDesignSystem
         ↓
OpenTuneDesignSystem.typography
         ↓
Feature UI
```

## API

```kotlin
import com.arturo254.opentune.core.designsystem.OpenTuneDesignSystem
import com.arturo254.opentune.core.designsystem.theme.typography

val type = OpenTuneDesignSystem.typography
Text(text = song.title, style = type.songTitle)
```

## Roles y mapeos iniciales

| Rol | Material 3 vigente |
| --- | --- |
| `screenTitle` | `headlineLarge` |
| `sectionTitle` | `titleLarge` |
| `songTitle` | `titleMedium` con peso Bold |
| `songSubtitle` | `bodyMedium` |
| `metadata` | `labelSmall` |
| `badge` | `labelSmall` |
| `playerTitle` | `titleLarge` |

Estos mapeos centralizan el significado y mantienen el tipo `TextStyle`.
No se fijan fuentes, tamaños, line heights ni tracking fuera de
la tipografía Material activa.

## Primera migración

En `UniversalSearchScreen`, cada fila de resultado utiliza estos roles
para título, artista, proveedor, calidad y badge. Los estilos calculados son
equivalentes a los que usaba esa fila antes del cambio.

No migramos toda Home, Library, Player o Settings en 3.4:
esa tarea pertenece a 3.15. No se modifica el layout del Player.

## Compatibilidad y pruebas

`TypographyTokensTest` verifica:

- Equivalencia de los estilos existentes en Search.
- Mapeo de títulos y Player a la escala Material sin nuevas medidas.
- Reacción a cambios de tipografía activa, incluyendo familias y métricas.

El Safety Gate debe pasar unit tests, Android lint y APK universal debug.
Prueba de dispositivo recomendada: buscar canciones, comprobar que no cambie
el alineamiento de filas/badges y alternar fuente OpenTune/Sistema/Monocraft.

## Límite de alcance

Material 3 sigue gobernando la escala tipográfica. No tocamos fuentes
globales, preferencias, accesibilidad, glass ni el diseño visual.
