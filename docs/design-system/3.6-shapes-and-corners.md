# 3.6 — Sistema unificado de shapes y esquinas

Fecha: 2026-10-10
Rama: `opentune-rebuild-v1`

## Objetivo

Centralizar los radios y las formas de OpenTune sin rediseñar las
pantallas y sin anular la personalización actual de portadas.

## Contrato

`MaterialTheme.shapes` sigue siendo la fuente de verdad para
`extraSmall`, `small`, `medium`, `large` y `extraLarge`.

`OpenTuneDesignSystem.shapes` añade roles propios de OpenTune:

| Token | Valor actual |
| --- | --- |
| listArtwork | Rounded 14 dp |
| gridArtwork | Rounded 18 dp |
| searchArtwork | Rounded 17 dp |
| artwork | radio configurable del usuario, por defecto 16 dp |
| mediaCard | Rounded 22 dp |
| badge | Rounded 12 dp |
| pill | Rounded 50 % del componente |
| sheet | Rounded 30 dp |
| glassControlCluster | Rounded 30 dp |
| glassCard | Rounded 24 dp |

Estos valores conservan la geometría actual. Las superficies de Liquid
Glass siguen recibiendo `RoundedCornerShape`, sin cambiar lens/shaders.

## Preferencia de la portada

La clave existente `ThumbnailCornerRadiusKey` no cambia. El rango de
personalización actual es 0–45 dp y la opción predeterminada 16 dp.

```text
ThumbnailCornerRadiusKey
           ↓
MainActivityThemeHost
           ↓
OpenTuneTheme(artworkCornerRadiusDp)
           ↓
ProvideOpenTuneDesignSystem
           ↓
OpenTuneDesignSystem.shapes.artwork
```

`artworkShapeFor(radiusDp)` permite que el selector renderice la vista
previa mientras el usuario mueve el slider, sin guardar prematuramente
la preferencia. Los valores inválidos se sanitizan.

Los componentes antiguos que ya leen la preferencia no se migran
todavía; se mantienen hasta 3.15. La portada de Search utiliza
`searchArtwork` con los 17 dp anteriores para preservar su diseño
independientemente de la preferencia global en esta etapa.

## Consumidores migrados

- `UniversalSearchScreen.kt`: mediaCard, searchArtwork y badge.
- `LiquidGlassControls.kt`: icon/pill (50 %), cluster (30 dp) y card
  (24 dp por defecto, preservando el argumento custom `cornerRadius`).
- `ThumbnailCornerRadiusSelector.kt`: el preview dinámico de portada y
  la superficie de diálogo, ambos con la misma geometría.
- `constants/Dimensions.kt`: radios legacy 14 y 18 dp derivados de
  `OpenTuneShapeRadii`, sin cambiar consumidores.

## Pruebas

`ShapeTokensTest` verifica:
- geometría legacy;
- mapeo de Material 3;
- preferencia 0–45 dp y aislamiento de otros componentes;
- sanitización de valores inválidos.

CI: `testUniversalDebugUnitTest`, `lintUniversalDebug`,
`assembleUniversalDebug`. Probar en dispositivo los ajustes de
radio de portadas, Search, botones/glass y Player. No ejecutar
transformaciones masivas de shapes: pertenecen a 3.15/3.16.

## Fuera de alcance

Elevaciones/bordes/opacidad 3.7; Motion 3.8; efecto óptico Glass 3.9;
migración visual masiva 3.15. No se cambia el schema Room.
