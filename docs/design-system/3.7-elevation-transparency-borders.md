# 3.7 — Tokens de elevación, transparencia y bordes

Fecha: 2026-10-10
Rama: `opentune-rebuild-v1`

## Objetivo

Centralizar elevaciones, radios de sombra, transparencias y bordes
utilizados por OpenTune sin cambiar su aspecto ni efectos ópticos.

## Arquitectura

```text
MaterialTheme.colorScheme ──────────┐
                                    ├── OpenTuneSurfaceTokens
Current glass/card values ──────────┘
                                    ↓
                     OpenTuneDesignSystem.surfaces
                                    ↓
              elevations / shadows / opacity / borders
                                    ↓
            GlassBackdrop / GlassControls / Search
                Artwork Preview / Release Notes
```

Material 3 sigue siendo la fuente de verdad para superficies y elevaciones
estándar. `OpenTuneDesignSystem.colors` (3.3) conserva los colores de
glass fallback, glass outline y overlay de artwork.

## Elevación y sombras

| Token | Valor heredado |
| --- | --- |
| elevations.flat | 0 dp |
| elevations.releaseNotesCard | 4 dp |
| elevations.releaseNotesSurfaceTint | 6 dp |
| elevations.artworkSettingsDialog | 6 dp |
| shadows.glassOuterRadius | 8 dp |
| shadows.glassInnerRadius | 4 dp |

La sombra y la elevación tonal no son equivalentes.

## Bordes

| Token | Valor heredado |
| --- | --- |
| borders.fallbackGlassWidth | 0.8 dp |
| borders.activeGlassWidth | 0.75 dp |
| borders.glassCardWidth | 0.8 dp |
| borders.artworkPreviewWidth | 1 dp |
| borders.glassCardPureBlackColor | white 18 % |
| borders.glassCardStandardColor | white 22 % |
| borders.glassCardOpaqueColor | outlineVariant 20 % |
| borders.artworkPreviewColor | outline 50 % |

Los dos últimos colores siguen el ColorScheme dinámico o personalizado.

## Transparencia

Se preservan exactamente los valores previos: icon selected 10 %, pill
selected 11 %, cluster opaque 92 %, artwork active overlay 28 %,
inner glass shadow dark/light 22 %/14 %, glass card black gradient
7.5 % / 4.5 % / 4.5 %, light gradient 16 % / 5.5 % / 8 %,
opaque gradient end 82 %.

El overlay de carga de Search usa el rol ya existente
`OpenTuneDesignSystem.colors.overlayArtwork` (24 %) sin duplicarlo.

## Migración inicial

1. `LiquidGlassBackdrop.kt`: width, shadow radii y alpha interior.
2. `LiquidGlassControls.kt`: alpha, glass card gradient y borde.
3. `UniversalSearchScreen.kt`: overlay de reproducción y de carga.
4. `ThumbnailCornerRadiusSelector.kt`: borde preview y elevación tonal.
5. `ReleaseNotesCard.kt`: elevación y superficie tonal.

`SurfaceTokensTest` valida valores heredados y dependencia temática.
