# 3.13 — Sheets, dialogs, menus y context menus

Primitivas base: OpenTuneSheet, OpenTuneDialog, OpenTuneMenu,
OpenTuneContextMenu, OpenTuneMenuItem.

Conservan estado, gestos, callbacks y focus en sus consumidores:
- BottomSheetMenu delega a OpenTuneSheet con mismas opciones Material 3.
- DefaultDialog conserva LiquidGlassCard y radio de 30dp.
- BottomSheet conserva 16dp colapsado / 0dp expandido.
- FloatingNavigationToolbar mantiene menú contextual con estilo 24dp,
  colores y elevación tonal previos.

Migración restante: 3.15, limpieza 3.16. Pruebas en móvil: abrir/cerrar
dialogs y sheets, Back, IME, menús, navegación y Glass ON/OFF.
