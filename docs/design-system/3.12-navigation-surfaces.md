# 3.12 — App bars, Navigation Bar, Rail y Toolbar

Se crea `core/designsystem/navigation/NavigationComponents.kt` con
`OpenTuneAppBar`, `OpenTuneNavigationBar`, `OpenTuneNavigationRail`,
`OpenTuneFloatingToolbar` y `OpenTuneDestination`.

La API base recibe rutas, iconos y callbacks; no instancia NavController ni
duplica el back stack de la app. Las barras tradicionales siguen en Material 3.
La nueva Floating Toolbar optativa utiliza GlassSurface.

La implementación especializada existente `FloatingNavigationToolbar`
conserva gestures, selected route, shuffle y reconocimiento musical, y ahora
recibe sus dimensiones de `OpenTuneNavigationDimensions` sin cambiar
tamaños ni radio: 58dp alto, radio 30dp, padding 5/4dp, ancho 320dp para
etiquetas. Migración de shell completo: 3.15.

CI: tests, lint y universalDebug; físico: nav bottom, rail/tablet,
scroll, deep links, Search, FAB de reconocimiento y mini-player.
