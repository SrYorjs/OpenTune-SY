# 4.16 — Migración de V8 al motor unificado

Rama: `opentune-rebuild-v1`. Base: correcciones de 4.14–4.15 tras detectar errores de compilación en el Safety Gate.

## Arquitectura

```text
PlayerHost + PlayerState + PlayerActions + PlayerProgress
                         │
               PlayerLayout IMMERSIVE
                         │
                   V8PlayerScene
                   │          │
           V8PlayerBackdrop   V8PlayerControlsContent
                │                   │
       PlayerVisualState             ├─ PlayerActions callbacks
         Canvas / cover              ├─ GlassTrack + PlayerSeekSession
       visual animation              ├─ V8VolumeSlider
                                     ├─ Queue / Up Next
                                     └─ PlayerPanelMenus + codec
```

## Cambios implementados

- `ui/player/v8/V8PlayerComponents.kt`: concentra el backdrop Canvas/imagen, los controles Apple Music/Liquid Glass, volumen, la pista siguiente, reproducción, shuffle/repeat, fila secundaria de Queue y `GlassTrack`. Se extrajo del antiguo `PlayerComponents.kt` sin rehacer sus efectos ni sus dimensiones.
- `V8PlayerScene.kt`: una sola composición portrait/landscape, con mismas WindowInsets Horizontal+Bottom, peek de Queue, nested scroll y spacer 24/16dp. Conserva el identificador de animación del backdrop que utilizaban ambas orientaciones.
- `Player.kt`: dos escenas llaman al mismo `v8ControlsContent` con la totalidad de argumentos existentes; conserva `playerVisuals.artworkUrl`, `canvasArtwork` y `isPlaying`.
- El transporte del nuevo módulo recibe callbacks de un único `rememberPlayerActions`; no consulta ni controla Media3 por sí mismo. Se preservan animaciones de play/pause, feedback Liquid Glass, disabled, forma, tamaños y los modos shuffle/repeat.
- `Queue.kt` importa `QueueCollapsedContentV8` desde su ubicación nueva, preservando Letras/Queue/dispositivo.
- La barra de progreso y el códec siguen usando `calculatePlayerProgress` y `playerFormatBadgeLabel`, respectivamente. El volumen sigue siendo el `playerVolume` del servicio.

## Límites

No se crean un segundo temporizador, MusicService, ExoPlayer o sistemas de preferencias. Canvas sigue teniendo el mismo ciclo de vida y fuente del visual engine. No se modifican descargas, Together, crossfade ni los controles de V1–V7.
