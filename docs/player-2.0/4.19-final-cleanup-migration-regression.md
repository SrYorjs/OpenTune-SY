# 4.19 — Eliminación de duplicación y cierre del Player 2.0

Rama: `opentune-rebuild-v1`; cadena de Player 2.0 de 4.0 a 4.19.

## Cambio final aplicado

1. Se corrigió el test histórico de 4.8 que buscaba `LiquidGlassIconButton` en `PlayerComponents.kt` cuando V8 ya vive en `ui/player/v8/V8PlayerComponents.kt`. Esto había impedido que el Safety Gate 4.16/4.17 avanzara a Lint.
2. `V8PlayerControlsContent` ya no vuelve a observar `currentSong`/favoritos ni `shuffleModeEnabled` desde `PlayerConnection`. Recibe `liked` y `shuffleModeEnabled` del mismo `PlayerState` que consume el Player completo y el MiniPlayer.
3. V8 recibe la misma instancia de `PlayerActions` del Player padre; se eliminó `rememberPlayerActions` duplicado en la capa visual. Comandos de favorito, repeat, shuffle, next, previous y play/pause siguen usando Media3/PlayerConnection a través de PlayerActions.
4. Se eliminaron nueve parámetros sin uso de `V8PlayerControlsContent`, los dos parámetros muertos `showCodecOnPlayer/currentFormat` del componente de cola V8 y 60 importaciones históricas del módulo extraído.
5. Se mantiene un solo slot `v8ControlsContent` para portrait y landscape y una escena `V8PlayerScene` común; la lógica V1/V3, los módulos V2/V5/V7, Queue, Lyrics, fullscreen, SourceResolver, Together y crossfade no fueron eliminados.
6. `PlayerPresentationPreferences` continúa consumiendo las claves DataStore históricas `playerDesignStyle`, `playerBackgroundStyle`, `player_buttons_style`, `sliderStyle`; no hubo renombramiento ni reseteo.

## Arquitectura final

```text
MusicService / Media3 / QueueController
                  │
           PlayerConnection
                  │
      PlayerState + PlayerActions
                  │
            PlayerHost
                  │
     PlayerLayout + VisualSkin
                  │
 ┌────────────┬────────────┬──────────────┐
 V1/V3/V4/V6 V2 / V5 / V7       V8
  Classic     Visual modules   Glass/Canvas
                  │
         MiniPlayer / Queue / Lyrics
```

No se añadió otro servicio de audio, motor Media3 ni ticker. La eliminación afecta exclusivamente código duplicado y suscripciones de presentación, no funcionalidades históricas.

## Regression Gate

Las nuevas pruebas `PlayerFinalCleanupRegressionTest` protegen los enrutadores V1–V8, las claves persistidas, un único slot V8, `PlayerActions` compartido y la ausencia de otro motor de audio en los módulos visuales. Las suites 4.1–4.18 permanecen activas. Para dar por finalizada 4.19 se requiere Safety Gate en verde (tests + Lint + APK) y prueba real en dispositivo.

Checklist práctico:
- V1–V8: diseño, accesibilidad, controles, Full/MiniPlayer, orientation.
- Media3: play/pause, skip, seek, repeat-one/all, shuffle, queue reordering, radio incremental.
- Audio: MusicService, calidad real resuelta por Sources, crossfade, buffering y offline.
- Navegación: Queue, Lyrics, menús, Back, AOD, notificaciones, Together.
- Personalización: restaurar V1/V3, elegir V8 Canvas/Liquid Glass, tema dinámico/fondo negro y verificar persistencia tras relanzamiento.
- Rendimiento: jank, frames, memoria y uso de CPU deben medirse físicamente; no inferir un resultado de tests estáticos.
